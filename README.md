# Журнал авто для LiXiang 🚗📘

Исходный проект Android Studio для приложения **журнал / дневник автомобиля LiXiang (理想汽车)**.

Проект создан как:
- личный журнал
- исследовательский проект
- эксперимент под Android Automotive / Automotive-like систему Li Auto

---

## 📱 О проекте
Приложение предназначено для:
- фиксации поездок
- заметок по эксплуатации
- наблюдений за системой автомобиля
- экспериментов с Android Automotive

Проект публикуется **как есть**, без попытки обхода систем безопасности автомобиля.

---

## ⚠️ Важно
- ADB на серийных прошивках Li Auto **заблокирован**
- Passenger screen использует **whitelist приложений**
- Проект не является:
  - взломом
  - обходом защиты
  - модификацией прошивки

---

## 📦 Что внутри
- исходники Android Studio
- стандартная структура Gradle
- без build-артефактов

Проект распространяется в виде ZIP-архива.

# LiXiang Car Journal 🚗📘

Android Studio source project for a **car journal / diary application** designed for  
**Li Auto (LiXiang / 理想汽车)** vehicles.

This project is published as a **research and experimental work** related to
Android Automotive–like systems used in modern vehicles.

---

## 📱 About the project

The application is intended for:
- logging trips and vehicle-related events
- keeping maintenance and service notes
- personal observations during vehicle operation
- UI and UX experiments for in-car systems

The project reflects **practical experimentation**, not a production-ready solution.

---

## 🔧 Technical context

- Platform: Android / Android Automotive–like environment
- Target device: Li Auto (LiXiang) infotainment system
- Development tool: Android Studio
- Distribution: source code only

---

## ⚠️ Known limitations

- ADB is **blocked** on production Li Auto firmware
- Passenger display uses a **strict application whitelist**
- Installing third-party APKs is restricted by the system
- The default launcher cannot be replaced without privileged access

This repository **does not provide bypasses or exploits** for these limitations.
